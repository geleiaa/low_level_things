- C#/Powershell Weaponization

- Staged payloads can either work in memory or by dropping executables on disk. Droppers can be either pe/dlls, powershell files, c# scripts or anything that contains the full payload. Stages are mostly executed in memory and contain only a small blob of shellcode which download and execute a larger stage. Metasploit and Cobaltstrike provide dlls as stages which are download and executeed in memory however none of them provide stage-auth support.

#### Code exec technique

- steps for shellcode execution
- plus opsec: ppid spoofing, cli arg spoofing, remote proc injection

#### DLL Sideloading

- Enumerate windows processes to search for Dlls which:
    - Are not statically linked
    - Does not contain full path to load from LoadLibrary api
    - Contains DllMain or any other exported function executions
    - Are loaded and hit function entrypoint breakpoints during the initialization of the executable
    - Use tracebacks to hunt for execution flow od Dll

- https://crypt0ace.github.io/posts/DLL-Sideloading/
